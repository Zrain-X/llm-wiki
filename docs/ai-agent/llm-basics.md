# LLM 基础速查

## Token

Token 是模型处理输入输出时使用的基本离散单位，不等同于固定数量的汉字、字符或英文单词。

影响：上下文占用、输出限制和 API 计费通常都以 Token 为核心单位。

## Context Window

Context Window 是一次推理能够纳入的上下文范围。实际使用时要同时考虑：

- 系统提示词；
- 历史消息；
- 用户输入；
- 工具结果；
- 输出预算。

“模型支持 200K”不等于每次都应该塞满 200K。

## Tool Calling

模型负责选择工具并生成参数，真正执行工具的是宿主应用或 Agent Runtime。工具能力、权限和结果反馈决定了 Agent 能不能完成闭环。

## Reasoning

Reasoning 模型通常会投入更多推理计算来处理复杂任务。实际使用时需要在质量、延迟和成本之间取舍。
