# RAG

Retrieval-Augmented Generation 的核心是：在生成前先从外部知识源检索与问题相关的内容，再把结果作为上下文交给模型。

## 基本链路

```text
文档
  ↓
切分
  ↓
Embedding
  ↓
向量 / 混合索引
  ↓
Query 检索
  ↓
Rerank（可选）
  ↓
组装上下文
  ↓
LLM 生成
```

## 常见问题

- 切块过大或过小；
- 只做向量检索导致关键词命中差；
- 检索结果太多，占满上下文；
- 没有引用来源；
- 文档更新后索引没有同步；
- 把模型知识问题误判为检索问题。

实际工程里优先先保证检索质量，再讨论复杂 Agent 化流程。
